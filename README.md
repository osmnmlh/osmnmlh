### 🚀 About Me

- 🎓 **Computer Engineering** student focused on systems programming, developer tooling, and intelligent software architectures.
- ⚙️ **Systems & Automation:** Building **[myAgent](https://github.com/osmnmlh/myAgent)**, a local Windows desktop execution engine utilizing native Win32 API hooks, sub-millisecond hardware kill-switches, and local LLM orchestration.
- 🛠️ **Developer Tooling:** Developing high-performance CLI utilities and diagnostic engines in **Go** (such as **[aitrouble](https://github.com/osmnmlh/aitrouble)**).
- 🚀 **Embedded & Avionics:** Experience in flight telemetry, sensor data acquisition, and real-time avionics algorithms (**TEKNOFEST Rocket**).
- 🧠 **Computer Architecture:** Actively exploring microprocessors, low-level execution models, and local AI workflows.
