### 🚀 About Me

- 🎓 **Computer Engineering** student focused on robust backend architectures, autonomous AI systems, and modern software engineering.
- 🤖 **Autonomous AI Agents & Execution:** Creator of **[myAgent](https://github.com/osmnmlh/myAgent)**, a local Windows desktop execution engine utilizing native Win32 API hooks, sub-millisecond hardware kill-switches, and local LLM orchestration.
- 🛠️ **Developer Tooling & Concurrent Systems:** Author of **[aitrouble](https://github.com/osmnmlh/aitrouble)**, a high-performance CLI diagnostics tool built in **Go** for tracing breakage in AI integrations.
- 🚀 **Space & Mission Software:** Co-developed **[ANTIGRAVITY](https://github.com/osmnmlh/ANTIGRAVITY)** for the 2026 NASA Space Apps Challenge — an astronaut health monitoring platform integrating real-time SSE relay, Swift (iOS/watchOS), and web dashboards.
- 🧱 **Enterprise Platforms & Modularity:** Passionate about modular monoliths, multi-tenant B2B architectures, real-time messaging (WebSockets), client-side envelope encryption, and containerized micro-services.
- 🧪 **Algorithms & Simulations:** Developed **[optimus-vacuum-cleaner](https://github.com/osmnmlh/optimus-vacuum-cleaner)** (real-time grid pathfinding A*/BFS & FSM simulation) and predictive models like **[solar-storm-predicter](https://github.com/osmnmlh/solar-storm-predicter)**.
