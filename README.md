### 🚀 About Me

- 🔬 **Computer Architecture & AI Acceleration:** Leading a **TÜBİTAK 2209-A** research project investigating packing/unpacking overheads and vector acceleration for **4-bit AI inference on RISC-V Vector (RVV)** architectures (Orange Pi RV2).
- ⚙️ **Low-Level Systems & Autonomous Agents:** Architecting **[myAgent](https://github.com/osmnmlh/myAgent)**, a 100% local Windows AI desktop execution engine featuring native Win32 API hooks, sub-millisecond hardware kill-switches, and local LLM orchestration.
- 🚀 **Embedded & Avionics:** Developed real-time telemetry acquisition, sensor fusion, and flight computer algorithms for competitive rocketry (**TEKNOFEST Rocket**).
- 🛠️ **High-Performance Engineering:** Designing robust CLI tooling in **Go**, multithreaded systems, and performant backend services.
